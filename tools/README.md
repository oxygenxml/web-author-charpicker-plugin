# Unicode® character names

`src/main/resources/en_unicodechars.properties` maps each code point to its name and backs the
search by name in the "More symbols..." dialog. It is generated by `generate-unicodechars.js` from
`UnicodeData.txt` of the [Unicode Character Database](https://www.unicode.org/ucd/) (UCD).

## Updating to a new Unicode version

The Unicode Consortium releases a new version of the Unicode Standard every September; the release list is at
https://www.unicode.org/versions/enumeratedversions.html.

1. Generate the names for the new version:

   ```
   npm run generate-unicodechars -- --version 19.0.0
   ```

   This rewrites `src/main/resources/en_unicodechars.properties` and updates the version and
   copyright year of the Unicode Character Database entry in `third-party-components-character-data.xml`.
   The download uses `curl`, which must be on the `PATH`.
2. Check that the license text in `third-party-components-character-data.xml` still matches
   https://www.unicode.org/license.txt. The script only updates the year.
3. Review the diff of `en_unicodechars.properties`: a new release normally only adds names, so
   look into any removed or renamed entries.
4. Run the tests with `mvn test`. `SpecialCharServletTest` searches for specific names, and a
   search can return different results once new characters match it.

## Notes

- Characters that `UnicodeData.txt` lists only as ranges have no individual names and are left
  out: CJK Unified Ideographs, Hangul Syllables, Tangut Ideographs and similar.
- The translated `*_unicodechars.properties` files are not generated. Names missing from a
  translation fall back to English.
